# Einzelheiten zu offenen Punkten

Je offenem Punkt aus [OPEN-ITEMS.md](../../OPEN-ITEMS.md), der kein eigenes
Plan-Dokument hat, liegt hier eine Datei mit seinem Kürzel als Namen
(`KR1.md`, `SE1.md`, …). Bis zum 2026-11-21 standen diese Texte im Anhang der
Liste selbst und machten vier Fünftel der Datei aus.

Regeln:

- **Die Liste bleibt die EINE Liste.** Ob ein Punkt offen ist, steht nur in
  `OPEN-ITEMS.md`. Eine Datei hier ist nie ein eigener Aufgabenpunkt.
- **Eine Datei je Kürzel**, und das Kürzel steht als Zeile in der Liste —
  `pnpm check:doc-links` wird rot, wenn hier eine Datei ohne Zeile liegt.
- **Punkt erledigt:** der Eintrag zieht nach
  [OPEN-ITEMS-COMPLETE.md](../../OPEN-ITEMS-COMPLETE.md) (mit dem, was aus den
  Einzelheiten als Begründung und Beweis bleibt), die Datei hier wird gelöscht.
- **Kein Kästchen** in diesen Dateien; Teilpunkte tragen Buchstaben (a), (b), …
